# Real-Time Digital Signal Processing & Audio Frequency Visualizer (P5.js)

An interactive, web-based digital signal processing (DSP) application and real-time audio visualization matrix engineered utilizing JavaScript and the computational graphics engine P5.js. 

This repository serves as a technical case study in procedural audio data tracking, real-time frequency analysis, and algorithmic graphics mapping using frequency bands and octave scaling equations.

---

## 🏗️ Architectural Core & Systems Layout

The application processes live audio streams, mapping frequency data arrays directly onto hardware-accelerated canvas components:

* **Digital Signal Analysis:** Captures live audio outputs and maps amplitude, waveform, and frequency bands into readable data sets.
* **Octave Matrix Scaling:** Translates audio frequency distributions logarithmically into geometric properties, driving procedural graphics changes that match rhythmic pulses.
* **Dynamic Canvas Rendering:** Leverages lightweight web computing structures to achieve fluid visual transformations without incurring CPU overhead spikes.

## ⚡ Technical & Mathematical Milestones

* **Fast Fourier Analysis Baselines:** Successfully maps real-time raw waveforms into structured graphical modifications, replicating basic Fast Fourier Transform (FFT) visual modules.
* **Logarithmic Data Balancing:** Normalizes raw values using procedural calculations to prevent graphic clipping or visually erratic shapes during aggressive volume spikes.
* **Zero Engine Dependencies:** Relies entirely on native browser execution nodes and lightweight web math utilities to handle simultaneous sound and rendering processes.

## 🚀 Local Deployment & System Run

The visualizer operates inside any modern HTML5-compliant web browser environment. To deploy the application locally:

1. Clone or download this repository to your system workspace.
2. Extract the `Music Visualization App - Final Submission.zip` archive into an isolated folder directory.
3. Open the extracted directory to expose the application infrastructure (ensuring the `index.html` node is visible).
4. **Launch Method:**
   * **Modern Method:** Open the folder using an editor like VS Code and initiate the **Live Server** extension to host the localized instance.
   * **Alternative Method:** Launch the `index.html` file directly using an asset-compliant browser environment (Chrome, Firefox, or Safari) to review the execution loop.
